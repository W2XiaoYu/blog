# Cocos

从一个空场景开始，逐步认识节点、组件、资源和脚本，再把游戏送到不同平台。这里记录 Cocos Creator 学习与实践中值得留下来的部分。

## 内容导航

目前先从 2D 基础开始：

- [Cocos Creator 3.8.x 2D 基础](./cocos/basic-2d) — 节点、组件、UI、事件、资源和 2D 物理

后面再沿着这些方向慢慢补齐：

- 节点与组件 — 节点树、组件生命周期和常用 API
- 资源管理 — 资源加载、预加载与释放
- 动画与 UI — 动画、Widget、Layout 和基础界面组织
- 构建与发布 — Web、Android 等平台的构建注意事项

## 学习路线

```text
编辑器与项目结构
        ↓
节点、组件与生命周期
        ↓
TypeScript 脚本与事件系统
        ↓
资源管理、动画和 UI
        ↓
性能优化与多平台发布
```

## 约定

- 示例代码默认使用 TypeScript。
- 当前笔记以 Cocos Creator 3.8.x 为主，不使用 2.x 旧 API。
- 涉及平台构建、原生插件或渲染差异时，会单独标注目标平台。
